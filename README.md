# cpp-payment-system-polymorphism
A C++ program demonstrating runtime polymorphism using virtual functions and inheritance. It implements multiple payment methods such as UPI, Card, and Cash using a base Payment class.

# Payment System using Runtime Polymorphism in C++

## Concepts Used
- Class and Object
- Inheritance
- Virtual Function
- Runtime Polymorphism
- Function Overriding

## Payment Methods
- UPI Payment
- Card Payment
- Cash Payment

## Output
Payment made using UPI
Payment made using Card
Payment made using Cash
